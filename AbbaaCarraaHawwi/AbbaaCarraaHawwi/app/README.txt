Abbaa carraa hawwi - Android app (Kotlin)
1. Install Android Studio (Koala or newer).
2. File > Open > select this folder, let Gradle sync.
3. Run on a phone/emulator, or Build > Build APK(s).

No Android Studio? Upload this folder to a new GitHub repo (keep the .github folder).
Open the Actions tab > Build APK > when it finishes, download "Abbaa-carraa-hawwi-apk" (contains app-debug.apk).
